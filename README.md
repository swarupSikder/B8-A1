# B8-A1 – TypeScript Fundamentals

## Project Overview
This project contains solutions to 8 TypeScript programming problems and 2 technical blog posts. It demonstrates fundamental and intermediate TypeScript concepts, including functions, type narrowing, generics, interfaces, tuples, OOP, inheritance, access modifiers, and asynchronous programming.

## Problem Solutions
The `solutions.ts` file contains solutions to the following problems:
1) Multiply Value, Optional Parameters, Default Logic
2) Process Input, Union Types, Type Narrowing
3) Format Coordinate, Readonly Tuple
4) Concatenate Arrays, Generics, Rest Parameters
5) Popular Courses, Interface, Array Filtering
6) Pluck Values, Generics, `keyof`, Indexed Access Types
7) Employee & Manager, Classes, Inheritance, Access Modifiers
8) Validate Age Async | Promise, Async/Await, Error Handling

## Blog Posts
Two technical blog posts are included:
1) TypeScript Access Modifiers in OOP:
- `public`
- `private`
- `protected`
- `readonly`

2) Combining Union and Intersection Types in TypeScript
- Union Types (`|`)
- Intersection Types (`&`)

## Technologies Used
- TypeScript

## Learning Objectives
- Understand TypeScript type annotations and inference.
- Work with union and intersection types.
- Apply generics to create reusable functions.
- Use interfaces to define object structures.
- Understand OOP concepts, inheritance, and encapsulation.
- Handle asynchronous operations using Promises.
- Practice type safety and error handling.
